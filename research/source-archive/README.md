# Local Source Archive

Store complete source copies under `files/` when access terms, licensing, and
delivery permit. The directory is ignored by Git by default. Record each file's
relative path, byte count, media type, retrieval date, and SHA-256 in
`../source-manifest.yml`.

For text-searchable review evidence, place UTF-8 extractions under
`files/text/` and record the extraction method, byte count, and SHA-256. Do not
store credentials, DRM workarounds, or source material outside authorized
access.
